# Kavach brief alignment and release acceptance

The product authority is the user-supplied Kavach El Niño Readiness Copilot brief (archived in `docs/reference/original-project-brief.md`). Latur/chickpea is an example, not the scope boundary.

| Brief layer/value | Implemented prototype behavior | Honest limit |
|---|---|---|
| Farmer first | Ten Maharashtra districts; gram, rabi jowar, wheat; sowing/growing/water intent; stage/soil/moisture/irrigation selections | Synthetic visit profile, no measured field data or farmer usability trial |
| Sense | Actual CHIRPS monsoon rainfall, ERA5 modeled September surface moisture/air heat, NOAA ONI | Dated approximate town-centre grids; not current field or district-wide observations; no crop-health claim |
| Compare | Matching 30-year baseline and selected 2002/2009/2015/2023 histories with actual local variation | Selected examples, not causality or forecast |
| Decide | Pure versioned regional stress indicator; seven source-conditioned crop options, three scoped district contingencies; explicit missing facts and verification tasks | Experimental indicator; not calibrated farm loss. Discussion options are unreviewed mappings, not independently reviewed current prescriptions |
| Explain | Bounded Google model grounded in recomputed assessment; English/Hindi/Marathi voice/text; canonical visual components | Model/voice availability and language quality not guaranteed; no agronomic invention allowed |
| Useful application | Focused season/history/action/source views, conditional crop guidance, water comparisons, source-linked printable comparison, highlighted first-use tour | No automatic crop switch, insurance enrollment, saved farm record or dashboard-first workflow |
| Provenance | Source URLs/pages, observed/retrieved dates, geographic resolution, raw hashes, rule/method versions | Provenance is not scientific calibration or field validation |
| Google deployment | Independent web/API Cloud Run, Firestore shared quotas, Vertex/Speech, offline Earth Engine processing | BigQuery/Maps/ADK deliberately not added without need; no recurring EE jobs |

Never mark full brief completion while current reviewed agronomy, calibrated farm risk, crop-masked vegetation, reservoir-access linkage and verified insurance dates remain absent. Do not fill these gaps with pitch illustrations. See `season-readiness.md` for exact implemented methods and the backend ledger for observed validation/deployment status.
