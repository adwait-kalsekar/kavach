# Full Kavach brief audit — 18 October 2026

**The application is a working POC, but it does not yet implement the full Kavach vision.** Passing browser checks does not close the scientific, data coverage or agronomic-review gaps.

Authority: the user’s original `.context/kavach.md`, also archived in [the project brief](../reference/original-project-brief.md). Audited production baseline: `4e91101`. This change corrects the walkthrough defects found during that audit. Detailed browser captures, request/response evidence and acquisition notes remain in the ignored `.context/verification/audits/2026-10-18-full-brief/` directory.

## What was exercised

- Fresh desktop and phone browser contexts: 1440×1000, 393×852 and 393×540.
- The six-step walkthrough, actual highlight/dialog geometry, keyboard focus, next/back, skip, Escape, replay, completion and refresh. The correction passed **54 step/language/viewport combinations** locally, with zero dialog/highlight overlap, plus invalid and unavailable storage checks.
- Genuine deployed Google chat with Nanded, wheat and no irrigation: history requests contained 0, 2 and 4 prior entries; one-line and simple follow-ups stayed on topic. Typed answers were silent. Evidence expansion, navigation retention, mobile question index/composer and field-context reset worked.
- Genuine Google speech recognition, model response and synthesized audio in English, Hindi and Marathi, using prerecorded microphone fixtures. Recording cancellation made no provider requests. This is transport validation, not native-speaker or farmer-comprehension approval.
- All **30 district/crop assessments** through the deployed Hono API from the browser: rainfall arithmetic, four historical examples, matching baseline coverage, source/crop scope and published insurance dates. Individual insurance eligibility remained unverified. For pre-sowing contexts, 24 assessments reported an expired bulletin and six had historical-only guidance; none constituted a current reviewed prescription. The three crop choices in each region shared the same regional stress label.

Existing water, source-learning, failure-recovery and deployment checks complement these targeted probes. No new automated test cases were added. No Earth Engine compute, new service, quota increase or IAM change was needed for the audit.

## Interaction defects corrected

The old walkthrough kept English titles/body after a Hindi/Marathi language switch, mixed navigation labels, and placed the instruction card over highlighted controls on short phones. Its large evidence wrapper could produce a nearly full-screen highlight. Replay could briefly retain old geometry or refer to the wrong season subview.

The correction translates all six steps and controls, highlights the actual selectors/buttons/rainfall values, reveals targets at the start of the scroll region, measures without repeatedly scrolling, clamps the highlight, clears stale geometry and restores the overview before replay. Short screens receive a more compact dialog. A language selector is available inside the first-use dialog, with select and button controls included in the focus trap. Only `done` is accepted as the completion flag; unavailable storage still allows a usable first-visit tour and skip.

The final deployed chat inspection also found that a simple-language request could repeat the preceding one-line sentence verbatim, despite correct history and style metadata. Style-specific instructions now ask for different, everyday wording while respecting an explicit change of topic. One-line responses also join sentence boundaries with semicolons while preserving the model’s words. The adapter rejects an unchanged prior answer, including case/punctuation-only changes, for a requested rewrite. Existing numeric/view safety checks and the evidence fallback remain; there is no automatic paid retry. Validation must inspect distinct answer text, not merely the response’s style label.

## Priority to reach the actual vision

1. Define and evaluate crop risk using independent crop outcomes, then expand current official district/crop action coverage and obtain agronomic review. Do not relabel the regional indicator as personal risk.
2. Add crop-masked, quality-screened vegetation and a geographically honest locator/history view. Add current storage only with documented access. Keep query cost bounded and observations dated.
3. Make verified figures accessible in speech, then validate substantive language and comprehension with farmers/native speakers.
4. Review source before any public release; separately verify the final deck, video, links and submission receipt.

See [alignment matrix](brief-alignment.md) and [methods](season-readiness.md) for implementation details. These gaps are product work, not cosmetic fixes or capabilities that can be marked complete by enabling another Google service.
